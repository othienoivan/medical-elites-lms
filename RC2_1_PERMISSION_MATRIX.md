# RC2.1 Permission Matrix

| Resource | Student | Tutor | Institution Admin | Platform Admin |
|---|---|---|---|---|
| Announcements | Active tenant | Own authored records | Active tenant | Platform console only |
| Timetable | Active tenant | Own timetable entries | Active tenant | Platform console only |
| Examinations | Assigned/tenant workflows | Own/assigned records | Active tenant | Platform console only |
| Attendance | Own records | Own marked sessions | Institution | Audited support only |
| Gradebook/Submissions | Own attempts | Owning tutor | Institution | Audited support only |
| Clinical Logbook | Own entries | Assigned/reviewed entries | Institution | Audited support only |
| Wallet | No tutor wallet access | Own wallet | Institution wallet only | All finance wallets |
| Subscription plans | Read assigned entitlements | Read assigned entitlements | Read tenant subscription | Manage all |
