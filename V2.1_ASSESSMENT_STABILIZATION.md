# Medical Elites LMS v2.1 Assessment Stabilization

## Included fixes

- Tutor quiz lists now use rule-compatible ownership and assignment queries.
- Student quiz lists load only published quizzes assigned through course units.
- Quiz creation always writes canonical ownership metadata.
- Quiz writes remove undefined fields before Firestore submission.
- Quiz draft attempts use stable student/quiz ownership rules.
- AI-generated MCQ option identifiers are A, B, C and D rather than opt-1, opt-2, opt-3 and opt-4.
- The Question Bank View action now has a registered question-details route.

## Deployment

```bash
npm install
npm run build
firebase deploy --only firestore:rules,hosting
```

Both Firestore rules and hosting must be deployed.
