# v3.1.2 Tutor Storefront

## Added
- Public `/store/:sellerId` storefront route.
- Responsive tutor profile header with verified status, ratings, product totals and share-link action.
- Featured product section.
- Store-level search and product-type filtering.
- Published-product-only catalogue with pricing, thumbnails and featured badges.
- Tutor Commerce dashboard shortcut to the tutor's public storefront.
- Store unavailable and empty-result states.

## Security
- Storefront continues to use the existing published-product repository query.
- Draft, review, hidden and archived products are not exposed publicly.
