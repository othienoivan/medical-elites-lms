# Medical Elites LMS v1.2.2 — Learning Workflow Stabilization

## Corrected
- Flutterwave now returns authenticated donors to the LMS dashboard instead of the unresolved `medicalelites.org` domain.
- Added a real student self-service profile route and editable profile form.
- Student sidebar Profile now opens `/profile` rather than redirecting to Dashboard.
- Course-unit cards and details calculate module and lesson totals from Firestore records instead of stale counters.
- Module cards display actual lesson totals.
- Removed entry points to the unsaved generic lesson builder. Tutors create a lesson first and are taken directly into its saved builder.
- Added Move Earlier / Move Later controls to persist lesson sequence inside each module.
- Added module-level `quizRequired` configuration and pass-mark controls.
- Tutors can create a module quiz directly from module management or module editing.
- The last lesson in a module displays the published module quiz when one exists.
- Subsequent modules remain locked when the previous module requires a quiz until a passing attempt exists.
- Added AI quiz generation from the selected module's saved lesson text and extracted document content. Generated questions are stored in the Question Bank and selected for the quiz.
- Added a floating Medi AI assistant entry point to student, tutor and administrator workspaces.
- Added a safe route for `/tutor/learning-packages`, which previously reached the not-found page.

## Existing student management
Tutor student registration, editing and enrolment management remain available through Student Directory and Enrollment Manager. These screens provide the operational base for assigning and removing learners from programmes and course units.

## Deployment impact
Both Hosting and Functions must be deployed because the Flutterwave return URL is generated by `createDonationCheckout`.
